# Paris Fantasy

Old school RPG built with Macroquad : explore Paris Monuments, survive french food and become the tourist trap king.

## Play locally

Install Rust from [rustup.rs](https://rustup.rs/), then run:

```powershell
cargo run --release
```

Move with the arrow keys or WASD. Press Enter or Space near Alderfall to rest; in battle, use Up/Down and Enter to choose an action.

## Build for WebAssembly

```powershell
rustup target add wasm32-unknown-unknown
cargo build --release --target wasm32-unknown-unknown
Copy-Item target/wasm32-unknown-unknown/release/paris-fantasy-macroquad.wasm web/game.wasm
python -m http.server 8000 --directory web
```

Open `http://localhost:8000`. The matching miniquad web loader is bundled in `web/`; its MIT license is included alongside it.

## Use your own pixel map

Place a PNG at `assets/world.png` for desktop runs or `web/assets/world.png` for the browser build. Every source-image pixel is read independently at its native resolution; movement collision checks the PNG pixels beneath the character rather than snapping to tile-sized cells. Water-blue pixels and neutral gray rock pixels block movement. Unknown colors remain walkable, so paintings and non-tile maps work too. The map is drawn with nearest-neighbor filtering.

The built-in example PNG is generated by `build.rs` and embedded into the game as a fallback. Custom maps are not resized before collision checks.
